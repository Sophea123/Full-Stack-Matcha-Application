# 🍵 Matcha Application

A Flutter mobile application for ordering matcha, coffee, and dessert drinks.
The application provides a simple and modern interface where users can browse drinks,
customize their orders, add products to the cart, and place orders.

## 📱 Features

- 🏠 Home page
- 🍵 Browse Matcha drinks
- ☕ Browse Coffee drinks
- 🍰 Browse Dessert drinks
- 🔍 Search products
- 🛒 Add products to cart
- ➕ Increase/decrease quantity
- 📋 View product details
- 📏 Select drink size (Small / Medium / Large)
- 🧊 Select ice level
- 🍬 Select sugar level
- 📝 Add notes to an order
- 💰 Calculate total price
- 📦 Place orders
- 🧾 View order history
- 🕐 Display order date and time

## 🛠️ Technologies

- Flutter
- Dart
- Laravel
- MySQL
- REST API
